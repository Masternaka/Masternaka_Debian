# Démarrage rapide — Masternaka Debian

Super désigne la touche Windows. Maj désigne Shift.

| Raccourci | Action |
|---|---|
| Super + Entrée | Kitty |
| Super + Maj + Entrée | Terminal flottant escamotable |
| Super + Espace | Applications Rofi |
| Super + B | Firefox ESR |
| Super + F | Thunar |
| Super + E | Geany |
| Super + / | Tous les raccourcis |
| Super + Maj + T | Palette de couleurs |
| Super + Q | Fermer la fenêtre |
| Super + Maj + F | Plein écran |
| Super + Maj + Espace | Fenêtre flottante |
| Super + 1…0 | Espaces 1…10 |
| Super + Maj + 1…0 | Déplacer vers un espace |
| Super + moins / égal | Espaces 11 / 12 |
| Super + Alt + A | Mixeur audio |
| Super + S | Capture complète |
| Super + Maj + S | Capture d’une région |
| Super + Ctrl + Échap | Verrouiller |
| Super + X | Déconnexion, redémarrage, arrêt |
| Super + Maj + R | Recharger i3 |
| Super + Échap | Recharger les raccourcis sxhkd |

Après modification des services de session, se déconnecter puis se reconnecter.
Après un changement de configuration via l’installateur, faire de même.
Les captures sont enregistrées dans `~/Screenshots`.
