# Origine et modifications

Base : i3-setup de JustAGuyLinux (Drew), archive fournie par Gabriel le 28 septembre
2026. Commit indiqué par l’archive : `c5ac1bae8db8ef0f20f1d608e3eefaa3ee797085`.

Sources de provenance :
- https://codeberg.org/justaguylinux/i3-setup
- https://justaguy.dev/drew/i3-setup

Le fichier LICENSE est conservé sans modification (GNU GPL, version 2).
Les fichiers `i3/` proviennent de cette base ; les palettes originales sont
conservées. Les configurations suivantes ont été adaptées le 28 septembre 2026 :
polices, raccourcis, Dunst, Polybar, session, terminal, fonds et sélecteur de thèmes.
Les manifestes de thèmes ont été débarrassés des ressources externes absentes.
La configuration Picom conserve les animations de l’archive.

L’installateur, les scripts de compilation, les vérifications et la documentation
ont été réécrits pour Masternaka Debian. Ils sont distribués sous GPL-2.0-only.
Ce dépôt n’est ni le dépôt officiel de JustAGuyLinux ni une distribution Debian officielle.

Les noms des palettes identifient leurs couleurs d’origine ; ils ne signifient
pas que les thèmes GTK, icônes et fonds d’écran de leurs auteurs sont redistribués.
